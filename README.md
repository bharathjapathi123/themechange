# Theme Switcher Web App

## Overview
This is a simple and interactive Theme Switcher web application developed using HTML, CSS, Bootstrap, and JavaScript. The application allows users to switch between Dark and Light themes dynamically by entering the theme name in the input field.

## Features
- Switch between Dark and Light themes
- Dynamic background image changing
- Interactive user input handling
- Responsive layout using Bootstrap
- Simple and beginner-friendly project

## Technologies Used
- HTML5
- CSS3
- Bootstrap 4
- JavaScript

## How It Works
1. Enter `Dark` or `Light` in the input box.
2. Press the `Enter` key.
3. The background theme and heading color will change dynamically.
4. If an invalid theme is entered, an alert message will appear.

## Project Structure
- `index.html` → Structure of the webpage
- `themeswitch.css` → Styling for the application
- `themeswitch.js` → Theme switching functionality
